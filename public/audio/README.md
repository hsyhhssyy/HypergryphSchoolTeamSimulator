# public/audio — Placeholder BGM tracks

3 placeholder BGM tracks for the game, generated by
[`scripts/gen-placeholder-audio.mjs`](../../scripts/gen-placeholder-audio.mjs)
(a tiny dependency-free Node script — no ffmpeg, no samples).

## License / provenance

- **CC0 / public domain.** Every track is an original short sine-wave arpeggio
  composed programmatically for this project — no samples, no melodies copied
  from any existing work, nothing under copyright.
- Tracks are 16-bit mono WAV (44.1 kHz), ~12–15 s each, with a fade-out tail:
  - `track-01.wav` — C major pentatonic, 72 BPM (calm, menu-ish)
  - `track-02.wav` — D major pentatonic, 96 BPM (brighter, gameplay-ish)
  - `track-03.wav` — A minor pentatonic, 84 BPM (mellow, result-ish)

## Swapping in licensed music

The game reads the track list from `src/hooks/useAudioPlayer.ts`
(`TRACKS` array, static asset URLs like `/audio/track-01.wav`).

To ship real BGM:

1. Replace/add audio files in this directory (mp3/ogg/wav all work with the
   HTML5 `<audio>` element; the player does not care about the container).
2. Update the `TRACKS` array (display name + `src`) in
   `src/hooks/useAudioPlayer.ts`.
3. Make sure the music you add is properly licensed (royalty-free, CC0, or a
   license you own). The project MUST NOT ship copyrighted music.

Audio files are separate static assets served by Vite from `public/` — they
are lazy-loaded by the browser via `<audio src>` (`preload="metadata"`, so a
track's bytes are only fetched when its `<audio>` element is played) and are
never part of the JS bundle.
